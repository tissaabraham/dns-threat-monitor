# Dashboard Module

## Purpose

The **Dashboard** module provides a web-based user interface for visualizing and managing DNS logs and security alerts. This is the presentation layer of the system architecture.

## Responsibilities

- Display DNS logs and network activity
- Visualize detected alerts and threats
- Allow users to search and filter logs
- Display threat severity levels
- Show alert status tracking (new, acknowledged, resolved, archived)
- Provide real-time updates of network activity
- Present threat statistics and trends
- Enable manual threat status management

## Key Features

- Real-time dashboard with updated logs and alerts
- Search and filtering capabilities
- Threat severity visualization
- Alert lifecycle management interface
- Network activity statistics
- Threat trend analysis
- Response time monitoring

## Technology Stack

- Flask Web Framework
- Python Backend
- HTML/CSS/JavaScript Frontend
- SQLite database integration

## Key Components

- Web server and routing
- Dashboard views and templates
- Search and filter logic
- Real-time data update mechanisms
- Alert management interface

## Input/Output

- **Input**: DNS logs and alert data from the Database module
- **Output**: User interface for monitoring and managing network security
